2026-10-08 用户实测：面对“蓝色、750 美元以内”的需求，MiWu 用中文说明颜色无法确认，并展示预算内备选商品及链接。这展示中英文交互、真实商品卡片和证据边界，不证明全店最低价排序或图片颜色识别。

## 解决的问题

用户不必反复翻商品列表，可以直接描述需求、询问具体商品、比较候选。MiWu 通过真实工具读取商品证据，再生成受约束的回答。英文侧栏支持中英文输入，并展示商品图片、价格快照和真实商品链接。

## 已验证的成果

- **检索基础：**在 Multi-CPR 电商语料的 1,002,822 条 passage、1,000 条 dev query 上完成 BM25 / Dense / Hybrid / Reranker 对照。
- **真实集成：**Shopify 读取 17 个测试商品，15 个参与检索，打通 Adapter → UnifiedProduct → MiWuCore → FastAPI → App Proxy → Theme App Extension。
- **云端交付：**部署到与已有服务共用的 2核2G 级 ECS，使用独立服务、模型 API 与 HTTPS，避免加载本地大模型。
- **Agent：**历史 40 案例工具选择准确率 82.5%，商品序号引用解析准确率 75%；不是回答准确率 100%。
- **验证：**2026-10-03 回归快照为 61 项运行、59 项通过、2 项跳过；保留当时真实店铺搜索、中文需求及比较验收记录。2026-10-08 的复杂指定商品比较仍出现事实列表兜底，未完成价差计算，不能据历史验收声称所有比较请求均成功。

| 方法 | Recall@10 | MRR@10 |
| --- | ---: | ---: |
| BM25 | 0.287 | 0.161193 |
| Dense | 0.485 | 0.292127 |
| Hybrid | 0.492 | 0.297857 |
| Hybrid + Reranker | 0.501 | 0.314564 |

百万级离线检索与 15 商品 Shopify 云端演示是**两个验证范围**。不声称百万商品生产部署、高并发验证或线上转化提升。早期 RAG 实验存在解析失败和错误路由；完整口径和失败结果保留在[评测说明](docs/evaluation.md)。

## 面试展示重点

1. 将离线 RAG 能力接入真实业务数据与商店入口，而非只做聊天问答。
2. 用统一商品契约分离平台适配、检索/Agent 核心和 Web 展示。
3. 在资源限制下完成百万级本地检索与小规格服务器的轻量部署，并说明二者区别。
4. 通过分层评测、证据校验和实际失败案例判断系统边界。
5. 根据使用反馈将过大的全屏工作台改回克制的侧边导购栏。

## 如何体验

打开[真实 Shopify 演示店](https://miwu-ai-store.myshopify.com/)，点击 **Ask MiWu**，输入 `Help me find a snowboard`，再尝试“我想买蓝色滑雪板，预算不超过 750 美元；无法确认的条件请说明”。比较工具已实现，但复杂比较可能退回商品事实列表，尚需改进。

店铺可能有访问保护，不公开访问密码。需要时由作者安排演示；在线地址不构成持续可用承诺。商品页是实时价格和库存的最终依据。原始截图及端到端验收日期为 2026-10-03；新增中文证据边界截图来自 2026-10-08 用户实测，本展示材料整理日期为 2026-10-08。

核心代码不会随展示仓库公开；完整复现需要另行安排私有代码和数据审查。
